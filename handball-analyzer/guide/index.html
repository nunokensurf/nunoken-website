01 / INTRODUCTION

はじめに

Handball Analyzerは、試合中の出来事を記録し、その場の状況把握と試合後の分析につなげるWindows向けハンドボール試合記録・分析ソフトです。

RECORD

試合を記録

選手、シュート位置・コース、結果、TO、GK記録などを入力します。

ANALYZE

その場で分析

スコア、SHOT%、TO%、GK SAVE%、時間帯別得点などを確認します。

REVIEW

試合後に振り返る

Team Report、Career Report、試合記録レポートで読み解きます。

このガイドについて

確認できている内容を中心に説明します。ボタン位置など未確認の操作は、推測せず確認待ちと明記しています。

FREE / PRO

FREEでも分析機能を利用できます。主な違いは保存できる試合数とPDFファイル保存です。詳しくは12 FREE / PROを確認してください。

基本的な画面構成

  • 上部：スコア、試合時間、前半・後半、試合操作
  • 左側：自チーム／相手の切り替えと選手選択
  • 中央：SHOT POSITION、COURSE、攻撃種類、プレー結果
  • 右側：LIVE KPIとGK情報
  • 下部：TO、守備、タイムアウト、警告、退場、失格、7人攻撃、履歴編集など

02 / GETTING STARTED

初めて使うとき

試合の前に、自チーム、選手、対戦相手を準備します。選手は継続的なCareer Reportの基礎になります。

  1. STEP 1

    チームを登録する

    自チームとして使用するチーム情報を準備します。登録画面の入口と必須項目は実操作確認後に追記します。

  2. STEP 2

    選手を登録する

    選手はcanonical player identityで管理されます。同一人物を名前・背番号だけで推測統合しないでください。

  3. STEP 3

    背番号・ポジションを設定する

    各選手に背番号とポジションを設定します。変更手順は確認後に追記します。

  4. STEP 4

    対戦相手を準備する

    試合作成で使用する対戦相手を準備します。選手登録範囲と編集方法は確認待ちです。

詳細確認待ち

正式なボタン名、必須項目、保存操作はスクリーンショットと最新アプリの確認後に追加します。

03 / MATCH SETUP

新しい試合を始める

新しい試合を作成し、試合情報、出場メンバー、先発、GKを設定して記録を開始します。

  1. STEP 1

    新しい試合を作成

    試合作成画面への正式な移動経路は確認後に追記します。

  2. STEP 2

    大会名・会場等を入力

    試合情報とHOME / AWAYを設定します。必須・任意項目は確認待ちです。

  3. STEP 3

    メンバーを設定

    出場メンバー、先発、GKを設定します。

  4. STEP 4

    試合を開始

    設定内容を確認して記録を開始します。開始操作は確認後に追記します。

開始前に確認

HOME / AWAY、出場メンバー、先発、GKは試合中の入力とレポートに関係します。

04 / MATCH INPUT

試合を記録する

試合時計と対象選手を確認し、プレーの種類に応じて必要な情報を順番に入力します。

選手→SHOT POSITION→SHOT TYPE→COURSE→結果

SHOT

  1. STEP 1

    選手を選択

    自チーム／相手を確認し、シュートした選手を選びます。

  2. STEP 2

    位置・種類・コース

    SHOT POSITION、SHOT TYPE、COURSEを入力します。COURSEはシューターから見た方向です。

  3. STEP 3

    結果

    GOAL、GK SAVE、BLOCK、枠外を選びます。BLOCKはCOURSEなしでも保存できます。

入力制約

退場中の選手には新しいSHOT / TOを入力できません。

その他の記録

TO

ターンオーバーを記録。分類と確定手順は確認待ち。

退場・警告

対象チーム・選手を確認して記録。

タイムアウト

自チーム／相手を確認して記録。

7人攻撃

開始・終了の正式操作は確認待ち。

GK変更

出場GKの切り替え手順は確認待ち。

Undo

直前の入力を取り消します。

DF崩し方機能と得点差推移は廃止済みのため、このガイドでは扱いません。

05 / LIVE ANALYSIS

リアルタイム分析

概要、攻撃、守備 / GK、選手、時間帯を、前半 / 後半 / TOTALとHOME / AWAYで切り替えて確認します。

概要攻撃守備 / GK選手時間帯
  • 概要：スコアと主要KPI、前半から後半への変化
  • 攻撃：シュートと攻撃の集計
  • 守備 / GK：守備とGKの集計
  • 選手：選手別記録
  • 時間帯：1分単位、前半 / 後半を区別し、0得点時間帯も保持
操作確認待ち

分析画面を開く正式な経路と、各タブ固有の操作は実操作確認後に追加します。

06 / EDIT HISTORY

入力を間違えたとき

直前の入力はUndo、過去の入力は履歴編集から修正します。試合終了後も編集できます。

直前

Undo

直前に確定した記録を取り消します。

過去・終了後

履歴を編集

SHOT、TO、選手、GK関連記録の対象履歴を確認して修正します。

修正後の確認

修正はスコア、集計、GK記録、レポートに関係します。具体的な編集項目と確定手順は実操作確認後に追記します。

07 / FINISH MATCH

試合を終了する

前半終了、後半開始、試合終了の順に進行します。各操作の前に試合時間とスコアを確認します。

  1. STEP 1

    前半終了

    前半の記録を終了。時計の扱いは確認待ちです。

  2. STEP 2

    後半開始

    後半を開始し、前半と区別して記録します。

  3. STEP 3

    試合終了

    最終スコアと記録を確認して終了します。

  4. STEP 4

    結果確認・修正

    試合結果画面を確認し、必要なら終了済み試合の履歴を編集します。

08 / TEAM REPORT

Team Report

Team Reportは、チームの傾向と次の試合に向けた材料を整理する分析資料です。試合記録資料とは目的が異なります。

MATCH OVERVIEWATTACKSHOT MAP / COURSEDEFENSE / GOALKEEPERPLAYERS SUMMARYINSIGHTS / DIAGNOSISNEXT GAME FOCUS
  • 試合概要、主要指標、時間帯別得点
  • 攻撃、シュート位置・コース
  • 守備、GK、選手別サマリー
  • INSIGHTS / DIAGNOSIS、NEXT GAME FOCUS
  • TO → FASTBREAK分析

PDF PreviewはFREEでも確認できます。PDFファイル保存はPROで利用できます。開き方と保存操作は確認後に追記します。

09 / CAREER REPORT

Career Report

選手個人の記録を複数試合にわたって確認する分析資料です。CPとGKで専用レイアウトを使用します。

対象を選ぶ

選手を選択し、全試合、期間指定、または試合選択で集計対象を決めます。正式なフィルター操作は確認待ちです。

CP CAREER REPORT

コートプレーヤー

GOAL、SHOT、SHOT%、TO、SHOT POSITION、SHOT TYPE、COURSE、POSITION × TYPE、POSITION × COURSE、Feedback。

GK CAREER REPORT

ゴールキーパー

SA、SAVE、GOAL、SAVE%、被SHOT POSITION、通常COURSE、7M COURSE、POSITION × COURSE、Feedback。

COURSEはシューターから見た方向です。PDF PreviewはFREE、PDFファイル保存はPROで利用できます。

PDF

11 / DATA MANAGEMENT

Backup / Restore

Backupはアプリのデータを保存する仕組み、Restoreは作成済みBackupをアプリへ復元する機能です。

重要

DBファイルを直接コピー・編集せず、必ずアプリのBackup / Restoreを使用してください。Restore前に現在のデータをBackupし、復元後にデータ整合性を確認してください。

  1. STEP 1

    手動Backup

    アプリのBackup機能から保存します。保存場所の正式操作は確認待ちです。

  2. STEP 2

    自動Backup

    自動Backupがあります。作成タイミング、保存世代、保存場所は確認後に追記します。

  3. STEP 3

    Restore前Backup

    復元前の状態へ戻せるよう、現在のデータを手動Backupします。

  4. STEP 4

    Restore

    対象Backupを選びます。処理中はアプリ終了やPCの電源断を避けてください。

  5. STEP 5

    整合性確認

    DB整合性確認を実行し、チーム、選手、試合を確認します。

別PCへ移動

移行元PCでBackupを作成し、ファイルを安全に移して、移行先のアプリからRestoreします。内部DBを直接移動しないでください。

互換性について

現在のDB Schemaは20、Backup Formatは1です。異なるアプリバージョン間でRestoreする場合は、移行元で最新のBackupを作成してから実行してください。

12 / PLANS

FREE / PRO

分析機能の範囲は同じです。保存できる試合数とPDFファイル保存が主な違いです。

FREE¥0
  • 保存できる試合は1試合
  • PDF Preview可能
  • PDFファイル保存不可
  • Team Report、Career Report、リアルタイム分析、Backup / Restoreを含むその他の機能を利用可能
PRO¥5,000/月
  • 試合保存数無制限
  • PDF Preview可能
  • PDFファイル保存可能
  • すべての機能を利用可能
PROからFREEになった場合

既存試合を自動削除しない方針です。上限到達時の新規試合作成などの具体的挙動は確認後に追記します。

PROはMicrosoft Storeの月額Subscriptionとして販売予定です。現在は販売を開始していません。

13 / TROUBLESHOOTING

困ったとき

新しい試合を作成できない

FREEで保存できる試合は1試合です。保存済み試合数とプランを確認してください。その他は確認後に追記します。

PDFを保存できない

FREEはPDF Previewのみです。PDFファイル保存はPROの機能で、現在販売開始前です。

入力を間違えた／過去の試合を修正したい

直前はUndo、過去や終了済み試合は履歴編集を使用し、修正後に集計を確認します。

Backupを作成したい

アプリのBackup機能を使用し、DBファイルを直接コピー・編集しないでください。

別PCへ移したい／Restoreしたい

移行元でBackup、移行先でRestoreし、Restore前Backupと復元後の整合性確認を行います。

データ整合性を確認したい

アプリのDB整合性確認を使用します。正式な操作経路は確認後に追記します。

アプリが起動しない

PCを再起動して確認してください。正式な修復手順はサポート内容確定後に追加します。

問い合わせたい

お問い合わせ窓口は準備中です。正式決定後にこのページへ追加します。

最新アプリの実操作とスクリーンショットを確認しながら更新します。
