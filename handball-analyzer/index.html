WHY HANDBALL ANALYZER

試合の記憶を、
次の判断に変える。

紙や表計算での集計に追われず、試合中に入力したデータをそのままハンドボールの試合分析へ。監督・コーチ・分析担当者が欲しい視点を、一つのスコア記録アプリにまとめました。

  • 01試合中の記録を後から集計するのが大変
  • 02誰がどこから、どのようなシュートを打ったか分かりにくい
  • 03GKのセーブ率や被シュート傾向を確認したい
  • 04前半・後半や時間帯による流れを分析したい
  • 05選手の成長を複数試合で比較したい
  • 06分析結果をスタッフや選手へ共有したい

CORE FEATURES

入力からレポートまで。
試合分析を一つの流れに。

SHOT／TO／GK、退場、Undo、試合後の履歴編集に対応。記録した同じデータから、リアルタイムと試合後の両方を分析できます。

01 / MATCH INPUT

試合入力

選手と位置を選び、SHOT／TO／GK、退場などを記録。Undoと履歴編集で入力ミスにも対応します。

02 / LIVE

リアルタイム分析

攻撃成功率、SHOT%、TO%、GK SAVE%を試合中に確認できます。

03 / TEAM

チーム分析

攻撃・守備・シュート・GK・時間帯を、自チームと相手で比較します。

04 / PLAYER

個人キャリア分析

複数試合のGOAL、SHOT、SHOT%、TO、位置・コースを選手ごとに蓄積します。

05 / GOALKEEPER

GK分析

SAVE%、被シュート位置、シュート種類、コースからGKの傾向を確認します。

06 / TIMELINE

時間帯別得点

前半・後半の流れと、1分単位の得点推移を確認できます。

07 / PDF

PDFレポート

FREEでプレビュー、PROでPDFファイル保存。ミーティングや共有に使えます。

DB
08 / DATA CARE

バックアップ／復元

手動バックアップと復元に加え、起動時・試合終了時などの自動バックアップ、DB整合性確認を備えています。

WORKFLOW

記録が、そのまま
振り返りにつながる。

試合前の準備から終了後の共有まで、データを転記せず、一つの流れで進められます。

  1. 01試合を作成チームと選手を準備
  2. 02試合中に入力SHOT／TO／GKなど
  3. 03リアルタイム分析KPIと試合の流れを確認
  4. 04試合終了履歴を確認・編集
  5. 05チーム・個人レポート傾向と成長を振り返る
  6. 06PDF共有PROでファイル保存

FAQ

よくある質問

導入前に気になる料金、データ、通信についてまとめました。

FREE版だけでも利用できますか

はい。試合入力、リアルタイム分析、チーム分析、個人分析、PDFプレビューなどの主要機能を利用できます。

FREE版では何試合保存できますか

保存できる試合は1試合です。継続して複数試合を保存する場合はPROをご利用ください。

PDFを見ることはできますか

FREEでもPDFレポートをアプリ内でプレビューできます。PDFファイルとして保存する機能はPROで利用できます。

PRO版はいくらですか

月額5,000円です。無料試用期間や割引は設けていません。

PRO版の購入はどこから行いますか

FREE版をMicrosoft Storeからインストールし、アプリ内の「プランと購入」画面から購入します。

PRO契約を復元できますか

はい。「購入済みライセンスを復元」から、Microsoft Storeで利用しているMicrosoftアカウントの有効なPROライセンスを確認できます。

データはどこに保存されますか

試合・チーム・選手データは基本的に利用者のPC内へ保存されます。手動・自動バックアップも利用できます。

インターネット接続は必要ですか

試合入力やローカル分析はPC内で行います。アプリのインストール、PROの購入、購入状態の更新・復元にはMicrosoft Storeへの接続が必要です。

対応OSは何ですか

Windows 10／11に対応しています。スマートフォン版は提供していません。

英語で使用できますか

はい。Version 1.1から日本語と英語に対応しています。設定画面から表示言語を切り替えられ、対応済みの分析画面とPDFレポートにも反映されます。

問い合わせ方法は何ですか

Microsoft StoreのHandball Analyzer製品ページに掲載されるサポート情報をご確認ください。専用のお問い合わせページは現在準備中です。
