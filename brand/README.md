# nunoken logo concepts

Initial comparison assets. These files are not yet the final logo master.

- `logo-a-precision.svg`: neutral and scalable; closest to the current website wordmark
- `logo-b-data-grid.svg`: technical and data-oriented
- `logo-c-forward.svg`: sport and motion-oriented
- `index.html`: comparison board

After one direction is selected, create the production assets with adjusted custom letterforms, outlined paths, monochrome and reversed variants, minimum-size rules, and clear-space guidance.

## Symbol study

- `symbols.html`: symbol-mark comparison and apparel application board
- `symbol-a-trace*.svg`: a connected record-to-decision trace
- `symbol-b-orbit*.svg`: an open analysis cycle
- `symbol-c-shift*.svg`: converging forward motion

The symbol concepts are original geometric studies and are intentionally not tied to a specific sport.
